STRATEGY: RISE-FALL CONSISTENT
-------------------------------
TYPE: Trend entry with martingale recovery (HIGH RISK)

AUDIT CORRECTION (November 2026):
An earlier version of this guide described the bot as using a "1.071x multiplier" and called it
the safest robot for protecting a bankroll. That was wrong. The audit with the open-source
ORSTAC Agent (orstac-agent/) shows:

- After each loss the bot runs: stake += |last loss| x 1.071.
  The next stake is therefore about 2.07 times the previous one. This is a full martingale.
- "Max Loss Amount" only resets the stake after a single large loss. It does not stop the bot.
- The bot stops only when the expected profit is reached. It has no session stop-loss.

OPERATIONAL LOGIC:
- Market: Volatility 50 Index (R_50), Rise/Fall, short duration.
- Entry: short-term trend.
- Money management: martingale recovery as described above.

RISK (illustrative, reproducible):
- Balance 1,000, base stake 1: nine consecutive losses commit about 65% of the balance.
- 500 contracts, payout 0.954, win rate 50%: simulated ruin probability about 39%.
  Command: orstac-agent ruin --balance 1000 --stake 1 --multiplier 2.071 --payout 0.954 --contracts 500

IF YOU STUDY OR RUN IT:
- Add a session stop-loss and cap the number of progression steps.
- Use a demo account only. Do not use it on small real accounts.
